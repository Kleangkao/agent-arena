The offline idle Objective trial made ten injected calls at ticks 0, 120, 240, 360 and 480, with two sides each. Its empty picks intentionally leave the world idle and the Defender wins the pending clock. It demonstrates scheduler behavior only. For default Score, checkpoints are 0, 250+ boundary according to 8.334s; precise first checkpoint is tick 251 (25,100 units). A contact that appears and expires between checkpoints can be available to the engine and never appear in the model's view. If a fighter respawns just after a checkpoint after its queue was cleared, it can wait almost the full stride for a new plan. The audit cannot infer how a real model would react.

## Privacy and blind spots

Engine LOS uses continuous positions and no facing. Agent-to-agent collision neither occludes vision nor exposes hidden rival coordinates to the model. A path trying to approach can stop at an unseen opponent by collision, which is legitimate arcade feedback, though the protected prompt currently does not receive that event. Last seen is authorized position + sample time, up to 2.2s inclusive. The `contact.status` classification prefers passive visible, then a same-boundary focused sample, then last seen or unknown. Audited prompts omit private data. Inputs with close visible rivals were checked alongside spawn-hidden and defeated cases. That is evidence about the explicit serialization boundary, not a formal noninterference proof. Public roles and interaction progress, when combined with public map, intentionally convey limited general location information. See A14 for a design decision about the disclosure.

Server-managed reserve and storage lock configuration and identity. V2.5 injects coaching but zeroes memory revisions in the actual route and never calls reflection for this recording format. The adapter accepts matching local memory in tests, which is narrower than released persistent memory. The earlier V1 path remains the independent evidence.
