# Approved design versus observed V2.5

| Approved intent | Actual behavior and evidence | Assessment and uncertainty |
|---|---|---|
| V2 §§10–11, continuous motion and fine spatial decisions | 30 Hz fixed point, partial movement, redirect and stop before reaching any tile center. Geometry probe records 8910→9210 x before redirection. Target routes, model directions and policies still use centers. [Evidence](DIAGNOSTICS.json) | Meets world movement requirement. Movement freedom differs by input source. Steer is bounded by collision/time/stop, with no command-specific expiry. |
| V2 §§11–13, distinguish walk/run/crouch/jump and independent states | Low-speed movement can overlap reload/observe/standard attack. Jump commits one segment, can take damage, no separate altitude/landing timer. Crouch posture can coexist with full walk mode. [Matrix](ACTION_COMPATIBILITY_MATRIX.md) | Partial. Explicit owner decision on whether this crouch/walk combination is valid. |
| V2 §§14–16, legitimate perception and coherent arcade risk-reward | Continuous obstacle ray and range, no orientation, one focused sample and remembered valid location. Passive contact and attack eligibility/resolution are coupled, focused contact excluded. Posture changes hit without moving. [Evidence](DIAGNOSTICS.json) | Privacy shape supported, clarity and arcade design gap. Need a clear acquisition/eligibility contract. |
| V2 §§17–18, seeded fair outcomes and equal initial attributes | Equal 100 HP/4 ammo, dedicated seed lanes mirrored by high-bit reversal, existing 64 mirrored V2.5 match pairs. [Benchmark](../../evidence/gameplay-v25/benchmark.json) | Deterministic evidence for sampled conditions. Does not establish exhaustive edge fairness or objective balance across different controllers. |
| V2.4/V2.5, meaningful objective and scoring | Exact deadline, score precedence, target/equal-target draw, Core active after defeated Activator, respawn and role-swaps validated. [Tests](TEST_RUN.txt) | Mode logic supported. Public Core context and per-life observation/intent integration are incomplete. |
| V2 §§19–22, strategic decisions respond to public events without per-tick inference and reuse coaching/memory | Bounded provider checkpoints and a legal queue, with distinct coaching metadata. Narrow movement choices, no event digest, stale context between checkpoints, experimental route does not reuse compatible memory. [Interface](AI_INTERFACE_AUDIT.md) | No genuine V2.5 behavior evidence. V1 exists separately. |
| V2 §§25–28 and §§33–34, clear presentation and deterministic replay | Eight recording imports validated, one replay played and checked in browser, both combatants rendered, geometric diagnostic placeholders only. [Evidence](AUDIT_EVIDENCE.md) | Verified deterministic result. Playback gives richer state than agents, intermediate effect delivery under batching needs direct test. |
| V2 §§29–32, hosted isolation and versioned validation | Tested local gate/storage, protected adapter only. V1 independent settlement preserved, no V2.5 verifier. [Prior integration](../../evidence/gameplay-v25/integration.json) | Intentional local phase boundary, unfinished release acceptance. |
| Original master, consumer-grade guest coaching game | Public V1 preserved, local V2.5 browser is developer-facing. [Release boundary](../GAMEPLAY_V25.md) | No V2.5 consumer UI claim. Assets, trust documents and requirements preserved. |
