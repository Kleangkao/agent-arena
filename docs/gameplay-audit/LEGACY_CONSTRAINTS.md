# Legacy constraints by origin

| Baseline | Evidence and inherited behavior | Active effect / disposition |
|---|---|---|
| V1 sequential | `src/game.ts`, lane V1 replay and Solidity use their own bounded lane transcript, no continuous V2.5 commands. | Historical and public V1. No V1 movement/combat inside V2.5. Shared match reservation and identity remain an intentional release boundary. |
| V2.0 grid | `src/v2/yard.ts` defines cell IDs, obstacle and spawn positions, cardinal neighbor and pursuit. `src/v2/game.ts` defines map-scale ranges, HP/ammo, attack damage and route step caps. | V2.5 reuses world data and selected numbers, not grid line-of-sight; target routes and movement catalog still depend on cell centers and cardinal edges. The latter limits model flexibility (A03). |
| V2.1 concurrent actions | `src/v2/game.ts` historical sequential and concurrent functions have one per-side submitted intent. | V2.5 independent timers can overlap, but retains one command envelope per side per boundary (A13). Current world is not ticking at historical 440ms. |
| V2.2 realtime tile timings | `realtimeRules.stepMs` 110, with integer action, exposure, age timings and arcade accuracy. | Imported durations ×330 and shared odds. At current step 100, rounding still visible in timers (A05). Local developers intentionally keep 440ms strategic policy cadence. |
| V2.3 continuous position | `src/v23/game.ts`, `space.ts` implement fixed-point position, sweeps, motion state and geometry. | World no longer needs a committed tile for steer. L1 and waypoint route, rectangle occlusion, single passive visibility predicate, resolution-before-movement and short-lived focus are still active (A01, A06). |
| V2.4 Core | `src/v24/objective.ts` wraps shared world with public site and fixed phases. | Shared code receives V2.5 timings/live filters. Exact historical reference deliberately retains duplicate defeat data (A12). Current comparative policy still imported and may leave the Defender pursuing ordinary play (A09). |
| V2.5 mode extension | `src/v25/game.ts`, `server/gameplay-v25.ts` add score lives, public context and provider schedules above world. | Respawn/contact ordering gap and coarse checkpoints are new combinations, not proof of a V1 rule leak (A02, A07). V2.5 route still uses older catalog building blocks. |

Evidence supports the direct imports above. The repository has no baseline commit history, so chronological origin is inferred from version-labeled modules and approved amendment documents. Existing compatibility is intentional where isolated. Any change affecting authoritative events needs a new version and held historical fixtures. Fixes limited to renderer or prompt may keep the same engine version but should identify their own experimental cohort.
